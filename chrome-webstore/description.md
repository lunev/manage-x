ManageX automatically enables or disables your Chrome extensions based on the website you're visiting — so only the tools you actually need are active, right when you need them.

Most extensions run all the time, even on sites where you don't want them. ManageX lets you set simple URL rules so extensions turn on or off automatically as you browse, keeping your toolbar focused and reducing background clutter.

Key features:
• Extension rules — set "Enabled URLs" and "Disabled URLs" patterns for any installed extension, with wildcard support (e.g. *.example.com).
• Group rules — bundle several extensions together and control them with one shared rule.
• Automatic matching — rules are evaluated instantly whenever you switch or navigate tabs.
• Badge counter — see at a glance how many extensions changed state on the current page.
• Dashboard — one view of all your installed extensions and active rules.
• Export & Import URL Rules — back up your rules to a JSON file and restore them anytime, from the menu in the top right.
• Popup or side panel — use ManageX however fits your workflow.
• Keyboard shortcut — open ManageX instantly with Ctrl+Shift+E (Cmd+Shift+E on Mac).

ManageX runs entirely in your browser. Your rules and settings are stored locally using Chrome's storage APIs — nothing is sent to any external server.
