No login required.

1. Click the toolbar icon to open the popup.
2. In "Extensions", click an extension's icon to open its rule page. Under "Enabled URLs", enter a pattern (e.g. *.youtube.com), save.
3. Visit that URL in a new tab — the extension turns on automatically.
4. Back in the popup, double-click that extension's icon — it toggles on/off directly (icons controlled by an active rule can't be toggled this way).
5. Try "Extension Groups" the same way: click the "+" tile to create a group, add 2+ extensions, set a URL pattern, save.

Permissions: storage (save rules), management (toggle extensions), tabs (read active tab URL). No network requests; all data stays local.
